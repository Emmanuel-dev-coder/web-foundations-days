About QuickNotes

QuickNotes is used to quickly write, save and organize important notes and information.It helps users keep track of ideas, reminders, tasks and other useful information in one place

How to use QuickNotes

  1. Open QuickNotes
  2. Create a new note by clicking New Note
  3. Type your information
  4. Give the note a title for easy finding later
  5. Save the note if the app requires you to
  6. Edit or delete the note whenever you need
  7. use search to quickly finf an old note, if QuickNotes has a search option

Features

  • Edit notes
  • Delete notes
